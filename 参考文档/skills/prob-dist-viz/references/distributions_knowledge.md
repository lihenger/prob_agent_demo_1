---

## normal
- **名称**：正态分布（高斯分布）
- **公式**：f(x) = 1/(σ√2π) · e^{ −(x−μ)²/(2σ²) }，x∈ℝ
- **均值**：E(X) = μ
- **方差**：Var(X) = σ²
- **特征函数**：φ(t) = exp(iμt − σ²t²/2)
- **矩母函数**：M(t) = exp(μt + σ²t²/2)，t∈ℝ
- **典型应用**：测量误差、身高体重等生物度量、中心极限定理的自然极限、金融收益率近似。
- **关键性质**：
  1. 密度关于 x=μ 对称，呈钟形；μ 决定位置，σ 决定胖瘦。
  2. 线性变换不变：aX+b ~ N(aμ+b, a²σ²)。
  3. 独立正态的和仍正态。
  4. 标准正态分布 Z=(X−μ)/σ ~ N(0,1)，Φ(z) 表可查。
- **与其他分布关系**：二项分布/泊松分布在 n 大或 λ 大时近似正态；χ²、t 分布均由正态构造；对数正态是正态变量的指数。

---

## uniform
- **名称**：均匀分布（连续）
- **公式**：f(x) = 1/(b−a)，x∈[a,b]；否则 0
- **均值**：E(X) = (a+b)/2
- **方差**：Var(X) = (b−a)²/12
- **特征函数**：φ(t) = (e^{itb} − e^{ita})/(it(b−a))
- **矩母函数**：M(t) = (e^{tb} − e^{ta})/(t(b−a))
- **典型应用**：舍入误差、计算机随机数生成、等可能区间建模。
- **关键性质**：区间内任一子区间概率与长度成正比；缺乏记忆性不适用。
- **与其他分布关系**：是 Beta(1,1) 的平移缩放；大样本均值按中心极限定理趋于正态。

---

## exponential
- **名称**：指数分布
- **公式**：f(x) = λe^{−λx}，x≥0；否则 0（λ>0 为速率）
- **均值**：E(X) = 1/λ
- **方差**：Var(X) = 1/λ²
- **特征函数**：φ(t) = λ/(λ − it)
- **矩母函数**：M(t) = λ/(λ − t)，t<λ
- **典型应用**：泊松过程中独立事件的时间间隔、设备寿命、排队等待时间。
- **关键性质**：**无记忆性** P(X>s+t | X>s)=P(X>t)；与几何分布对应（离散版无记忆）。
- **与其他分布关系**：指数分布是 Gamma(1,λ) 与 Weibull(λ,1) 的特例；n 个独立同参数指数之和服从 Gamma(n,λ)；泊松过程的到达间隔服从指数分布。

---

## gamma
- **名称**：伽马分布
- **公式**：f(x) = β^α x^{α−1} e^{−βx} / Γ(α)，x>0（α>0 形状，β>0 速率）
- **均值**：E(X) = α/β
- **方差**：Var(X) = α/β²
- **特征函数**：φ(t) = (β/(β − it))^α
- **矩母函数**：M(t) = (β/(β − t))^α，t<β
- **典型应用**：等待第 α 个事件发生的时间、降雨量聚合、贝叶斯中若干共轭先验。
- **关键性质**：α 为整数时即 Erlang 分布；可加性：独立 Gamma(α_i,β) 之和仍 Gamma(Σα_i,β)。
- **与其他分布关系**：Gamma(1,β)=指数；Gamma(k/2,1/2)=χ²(k)；是泊松过程第 α 个到达时间的分布。

---

## beta
- **名称**：贝塔分布
- **公式**：f(x) = x^{α−1}(1−x)^{β−1} / B(α,β)，x∈(0,1)（B 为贝塔函数）
- **均值**：E(X) = α/(α+β)
- **方差**：Var(X) = αβ/((α+β)²(α+β+1))
- **特征函数**：无简单闭式（用合流超几何函数 ₁F₁ 表示）
- **矩母函数**：M(t) = ₁F₁(α; α+β; t)
- **典型应用**：比例/概率建模、贝叶斯中伯努利/二项试验的共轭先验、订单完成率估计。
- **关键性质**：支撑在 [0,1]；α=β=1 退化为 Uniform(0,1)；α=β 时关于 0.5 对称。
- **与其他分布关系**：X~Beta(α,β) 时 X/(X+Y) 形式关联 Dirichlet；与二项分布构成共轭对。

---

## chi_square
- **名称**：卡方分布（χ² 分布）
- **公式**：f(x) = x^{k/2−1} e^{−x/2} / (2^{k/2} Γ(k/2))，x>0（k 为自由度）
- **均值**：E(X) = k
- **方差**：Var(X) = 2k
- **特征函数**：φ(t) = (1 − 2it)^{−k/2}
- **矩母函数**：M(t) = (1 − 2t)^{−k/2}，t<1/2
- **典型应用**：方差推断、拟合优度检验、独立性检验（列联表）。
- **关键性质**：可加性：独立 χ²(k_i) 之和 ~ χ²(Σk_i)；k→∞ 时 (X−k)/√(2k) → N(0,1)。
- **构造来源**：χ² = Σᵢ₌₁ᵏ Zᵢ²，其中 Zᵢ 独立同分布 ~ N(0,1)；即 k 个独立标准正态变量的平方和。
- **与其他分布关系**：即 Gamma(k/2, 1/2)；n 个独立标准正态平方和 ~ χ²(n)；正态样本方差×(n−1)/σ² ~ χ²(n−1)。

---

## student_t
- **名称**：学生 t 分布
- **公式**：f(x) = Γ((ν+1)/2) / (√(νπ) Γ(ν/2)) · (1 + x²/ν)^{−(ν+1)/2}（ν 为自由度）
- **均值**：E(X) = 0（ν>1）；ν=1 时不存在
- **方差**：Var(X) = ν/(ν−2)（ν>2）；1<ν≤2 时为 ∞
- **特征函数**：无简单闭式
- **矩母函数**：不存在
- **典型应用**：小样本均值推断、回归系数显著性检验、方差未知时两样本 t 检验。
- **关键性质**：关于 0 对称，比正态厚尾；ν→∞ 时趋于 N(0,1)；ν=1 即柯西分布。
- **构造来源**：t = Z/√(V/ν)，其中 Z~N(0,1)、V~χ²(ν) 相互独立。
- **与其他分布关系**：Z/√(V/ν)（Z~N(0,1), V~χ²(ν) 独立）服从 t(ν)；是正态与卡方的构造组合。

---

## weibull
- **名称**：韦布尔分布
- **公式**：f(x) = (k/λ)(x/λ)^{k−1} e^{−(x/λ)^k}，x≥0（λ>0 尺度，k>0 形状）
- **均值**：E(X) = λ·Γ(1+1/k)
- **方差**：Var(X) = λ²[Γ(1+2/k) − Γ²(1+1/k)]
- **特征函数**：无简单闭式
- **矩母函数**：不存在
- **典型应用**：可靠性工程/失效分析、风速建模、极端值分析。
- **关键性质**：k=1 退化为指数；k=2 近似瑞利；k>1 失效率递增，k<1 递减。
- **与其他分布关系**：是极值分布族成员；指数分布与瑞利分布均为其特例。

---

## laplace
- **名称**：拉普拉斯分布（双指数分布）
- **公式**：f(x) = 1/(2b) · e^{−|x−μ|/b}，x∈ℝ
- **均值**：E(X) = μ
- **方差**：Var(X) = 2b²
- **特征函数**：φ(t) = e^{iμt} / (1 + b²t²)
- **矩母函数**：M(t) = e^{μt} / (1 − b²t²)，|t|<1/b
- **典型应用**：金融收益率尾部、差分信号建模、鲁棒回归的误差项（相比正态更厚尾）。
- **关键性质**：关于 μ 对称；尾部按指数衰减（比正态慢）；是两独立同参数指数变量之差。
- **与其他分布关系**：可表为两指数分布之差；在 L1 正则化（LASSO）中作为先验出现。

---

## lognormal
- **名称**：对数正态分布
- **公式**：f(x) = 1/(xσ√2π) · e^{ −(ln x−μ)²/(2σ²) }，x>0
- **均值**：E(X) = e^{μ+σ²/2}
- **方差**：Var(X) = (e^{σ²}−1)e^{2μ+σ²}
- **特征函数**：无简单闭式
- **矩母函数**：不存在
- **典型应用**：收入/财富分布、股价建模、保险理赔金额、颗粒尺寸。
- **关键性质**：右偏、仅取正值；ln X ~ N(μ,σ²)。
- **与其他分布关系**：正态变量的指数变换；与幂律/厚尾现象相关。

---

## bernoulli
- **名称**：伯努利分布
- **公式**：P(X=1)=p，P(X=0)=1−p（0<p<1）
- **均值**：E(X) = p
- **方差**：Var(X) = p(1−p)
- **特征函数**：φ(t) = 1−p + p e^{it}
- **矩母函数**：M(t) = 1−p + p e^t
- **典型应用**：一次成败试验、二项分布的基本单元、点击/转化建模。
- **关键性质**：最简单的离散分布；仅取 0/1。
- **与其他分布关系**：n 个独立同分布伯努利之和即 Binomial(n,p)。

---

## binomial
- **名称**：二项分布
- **公式**：P(X=k) = C(n,k) p^k (1−p)^{n−k}，k=0,1,…,n
- **均值**：E(X) = np
- **方差**：Var(X) = np(1−p)
- **特征函数**：φ(t) = (1−p + p e^{it})^n
- **矩母函数**：M(t) = (1−p + p e^t)^n
- **典型应用**：n 次独立成败试验中的成功次数、质量控制合格率、A/B 测试转化数。
- **关键性质**：可加性：独立 Binomial(n_i,p) 之和 ~ Binomial(Σn_i,p)；p=0.5 时对称。
- **与其他分布关系**：n 次独立伯努利之和；n 大、p 小、np 适中时近似 Poisson(np)；n 大时近似 N(np, np(1−p))。

---

## poisson
- **名称**：泊松分布
- **公式**：P(X=k) = λ^k e^{−λ} / k!，k=0,1,2,…（λ>0）
- **均值**：E(X) = λ
- **方差**：Var(X) = λ（均值=方差，为其典型特征）
- **特征函数**：φ(t) = exp(λ(e^{it}−1))
- **矩母函数**：M(t) = exp(λ(e^t−1))
- **典型应用**：单位时间/区域内稀有事件发生的次数、呼叫中心来话量、放射性衰变计数。
- **关键性质**：可加性：独立 Poisson(λ_i) 之和 ~ Poisson(Σλ_i)；在给定总数下，多类泊松可分解为多项分布。
- **与其他分布关系**：是二项分布在 n→∞、p→0、np=λ 固定时的极限；指数分布为其连续时间对应（到达间隔）。

---

## geometric
- **名称**：几何分布
- **公式**：P(X=k) = (1−p)^{k−1} p，k=1,2,3,…（首次成功所需试验次数）
- **均值**：E(X) = 1/p
- **方差**：Var(X) = (1−p)/p²
- **特征函数**：φ(t) = p e^{it} / (1 − (1−p)e^{it})
- **矩母函数**：M(t) = p e^t / (1 − (1−p)e^t)
- **典型应用**：首次成功所需试验次数、可靠性首次失效、与指数分布对应的离散无记忆分布。
- **关键性质**：**无记忆性** P(X>m+n | X>m)=P(X>n)；是离散等待时间分布。
- **与其他分布关系**：是负二项分布在 r=1 的特例；与指数分布构成离散/连续无记忆对。

---

## negative_binomial
- **名称**：负二项分布
- **公式**：P(X=k) = C(k+r−1, r−1) p^r (1−p)^k，k=0,1,…（第 r 次成功前的失败次数）
- **均值**：E(X) = r(1−p)/p
- **方差**：Var(X) = r(1−p)/p²
- **特征函数**：φ(t) = (p e^{it}/(1−(1−p)e^{it}))^r
- **矩母函数**：M(t) = (p e^t/(1−(1−p)e^t))^r
- **典型应用**：第 r 次成功前的失败次数、聚类/ contagion 事件建模、过度离散计数（泊松的推广）。
- **关键性质**：方差 > 均值（过度离散）；r=1 即几何分布。
- **与其他分布关系**：r 个独立几何分布之和；泊松在 λ 随机化（Gamma 先验）下边缘化为负二项。

---

## f
- **名称**：F 分布（费舍尔分布）
- **公式**：f(x) = [Γ((d₁+d₂)/2)/(Γ(d₁/2)Γ(d₂/2))]·(d₁/d₂)^(d₁/2)·x^(d₁/2−1)·(1+d₁x/d₂)^(−(d₁+d₂)/2)，x>0（d₁、d₂ 为自由度）
- **均值**：E(X) = d₂/(d₂−2)，d₂>2
- **方差**：Var(X) = 2d₂²(d₁+d₂−2)/[d₁(d₂−2)²(d₂−4)]，d₂>4
- **特征函数**：无简单闭式
- **矩母函数**：不存在
- **典型应用**：方差分析（两独立卡方之比）、回归方程整体显著性检验（F 检验）、两正态总体方差比检验。
- **关键性质**：右偏、仅取正值；d₂>2 时均值存在，d₂>4 时方差存在；F_{d₁,d₂} 的倒数 ~ F_{d₂,d₁}。
- **构造来源**：F = (U/d₁)/(V/d₂)，其中 U~χ²(d₁)、V~χ²(d₂) 相互独立；即两个独立卡方变量除以各自自由度之比。
- **与其他分布关系**：由两个独立 χ² 构造；t(ν)² ~ F(1,ν)；d₂→∞ 时 d₁·F → χ²(d₁)。
