## 章节知识

### ch01 — 随机事件与概率

- **样本空间**：随机试验所有可能结果的集合，记作 S 或 Ω
- **事件运算**：和事件 A∪B、积事件 A∩B、对立事件 Ā、差事件 A-B
- **概率公理化定义**：
  - 非负性：P(A) ≥ 0
  - 规范性：P(S) = 1
  - 可列可加性：互斥事件和概率等于概率和
- **条件概率**：P(A|B) = P(AB)/P(B)，P(B) > 0
- **全概率公式**：P(B) = Σᵢ P(Aᵢ)P(B|Aᵢ)
- **贝叶斯公式**：P(Aᵢ|B) = P(Aᵢ)P(B|Aᵢ) / Σⱼ P(Aⱼ)P(B|Aⱼ)
- **事件独立性**：P(AB) = P(A)P(B)
- **关键定理**：乘法公式、全概率公式、贝叶斯公式

### ch02 — 随机变量与分布

- **随机变量**：将样本空间映射到实数的函数 X = X(ω)
- **分布函数**：F(x) = P(X ≤ x)
- **离散随机变量**：概率质量函数 P(X = xᵢ) = pᵢ
- **连续随机变量**：概率密度函数 f(x)，F(x) = ∫_{-∞}^{x} f(t)dt
- **常见分布**：见下方「常见概率分布」部分
- **随机变量函数分布**：Y = g(X) 的分布

### ch03 — 多维随机变量

- **联合分布函数**：F(x,y) = P(X ≤ x, Y ≤ y)
- **联合分布律/密度**：离散用 pᵢⱼ，连续用 f(x,y)
- **边缘分布**：F_X(x) = lim_{y→∞} F(x,y)
- **条件分布**：P(X ≤ x | Y = y) = ∫_{-∞}^{x} f(u|y)du
- **随机变量独立性**：F(x,y) = F_X(x)F_Y(y)
- **协方差**：Cov(X,Y) = E[(X-EX)(Y-EY)] = E(XY) - EX·EY
- **相关系数**：ρ_{XY} = Cov(X,Y) / √(Var(X)Var(Y))
- **关键性质**：|ρ| ≤ 1，ρ=0 时不相关但不一定独立

### ch04 — 数字特征

- **数学期望**：离散 E(X) = Σ xᵢpᵢ，连续 E(X) = ∫ xf(x)dx
- **方差**：Var(X) = E[(X-EX)²] = E(X²) - [E(X)]²
- **协方差矩阵**：Σ = [Cov(Xᵢ,Xⱼ)]
- **矩**：k 阶原点矩 E(Xᵏ)，k 阶中心矩 E[(X-EX)ᵏ]
- **条件期望**：E(X|Y) 为关于 Y 的函数
- **性质**：
  - E(aX+b) = aE(X) + b
  - Var(aX+b) = a²Var(X)
  - 独立时 E(XY) = E(X)E(Y)

### ch05 — 大数定律与中心极限定理

- **切比雪夫不等式**：P(|X-EX| ≥ ε) ≤ Var(X)/ε²
- **辛钦大数定律**：独立同分布随机变量序列的算术平均依概率收敛于期望
- **伯努利大数定律**：频率依概率收敛于概率
- **林德伯格-列维中心极限定理**：独立同分布随机变量之和标准化后趋于标准正态分布
- **棣莫弗-拉普拉斯中心极限定理**：二项分布近似正态分布
- **应用**：用正态分布近似二项分布、确定置信区间

### ch06 — 统计量及其分布

- **总体与样本**：总体 X，简单随机样本 X₁,...,Xₙ
- **样本均值**：X̄ = (1/n)Σᵢ Xᵢ
- **样本方差**：S² = (1/(n-1))Σᵢ (Xᵢ-X̄)²
- **抽样分布定理**：
  - X̄ ~ N(μ, σ²/n)
  - (n-1)S²/σ² ~ χ²(n-1)
  - (X̄-μ)/(S/√n) ~ t(n-1)
- **三大抽样分布**：χ² 分布、t 分布、F 分布（见「常见概率分布」）

### ch07 — 参数估计

- **点估计**：用样本统计量估计总体参数
- **矩估计法**：用样本矩估计总体矩
- **极大似然估计（MLE）**：选择使似然函数最大的参数值
- **估计量评价**：无偏性 E(θ̂) = θ，有效性 Var(θ̂₁) < Var(θ̂₂)，相合性 n→∞ 时 θ̂ → θ
- **区间估计**：置信区间 [θ̂₁, θ̂₂]，置信水平 1-α
- **正态总体均值的置信区间**：σ² 已知用 Z 分布，未知用 t 分布

### ch08 — 假设检验

- **基本概念**：原假设 H₀、备择假设 H₁、显著性水平 α
- **两类错误**：第一类错误（拒真）概率 α，第二类错误（纳伪）概率 β
- **检验步骤**：提出假设 → 构造检验统计量 → 确定拒绝域 → 计算并判断
- **均值检验**：Z 检验（σ² 已知）、t 检验（σ² 未知）
- **方差检验**：χ² 检验（单总体）、F 检验（两总体）
- **拟合优度检验**：χ² 检验
- **p 值**：最小显著性水平，p < α 则拒绝 H₀

### ch09 — 方差分析与回归

- **方差分析（ANOVA）**：比较多个总体均值是否相等
- **单因素方差分析**：处理效应 + 随机误差
- **平方和分解**：SST = SSA + SSE
- **F 检验**：F = MSA/MSE，大于临界值则拒绝 H₀
- **一元线性回归**：Y = β₀ + β₁X + ε
- **最小二乘估计**：min Σ(yᵢ - β̂₀ - β̂₁xᵢ)²
- **回归系数检验**：t 检验 β₁ = 0
- **判定系数 R²**：衡量回归拟合优度

## 常见概率分布

### 连续分布

### normal — 正态分布

- **名称**：正态分布（高斯分布）
- **公式**：f(x) = 1/(σ√(2π)) · e^{ -(x-μ)²/(2σ²) }，x∈ℝ
- **均值**：E(X) = μ
- **方差**：Var(X) = σ²
- **特征函数**：φ(t) = exp(iμt - σ²t²/2)
- **矩母函数**：M(t) = exp(μt + σ²t²/2)，t∈ℝ
- **典型应用**：测量误差、生物度量、中心极限定理的极限分布
- **关键性质**：对称钟形；线性变换不变；独立正态和仍为正态

### uniform — 均匀分布

- **公式**：f(x) = 1/(b-a)，x∈[a,b]
- **均值**：E(X) = (a+b)/2
- **方差**：Var(X) = (b-a)²/12
- **典型应用**：舍入误差、随机数生成
- **特例**：Beta(1,1)

### exponential — 指数分布

- **公式**：f(x) = λe^{-λx}，x≥0（λ>0 为速率）
- **均值**：E(X) = 1/λ
- **方差**：Var(X) = 1/λ²
- **特征函数**：φ(t) = λ/(λ - it)
- **关键性质**：无记忆性 P(X>s+t|X>s)=P(X>t)
- **典型应用**：泊松过程事件间隔、设备寿命、排队等待

### gamma — 伽马分布

- **公式**：f(x) = β^α x^{α-1} e^{-βx}/Γ(α)，x>0
- **均值**：E(X) = α/β
- **方差**：Var(X) = α/β²
- **关键性质**：Gamma(1,β)=指数；可加性
- **典型应用**：等待第 α 个事件、降雨量、共轭先验

### beta — 贝塔分布

- **公式**：f(x) = x^{α-1}(1-x)^{β-1}/B(α,β)，x∈(0,1)
- **均值**：E(X) = α/(α+β)
- **方差**：Var(X) = αβ/((α+β)²(α+β+1))
- **关键性质**：支撑[0,1]；Uniform(0,1)=Beta(1,1)
- **典型应用**：比例建模、贝叶斯共轭先验

### chi_square — 卡方分布

- **公式**：f(x) = x^{k/2-1} e^{-x/2} / (2^{k/2} Γ(k/2))，x>0
- **均值**：E(X) = k
- **方差**：Var(X) = 2k
- **构造**：χ² = Σᵢ Zᵢ²，Zᵢ~N(0,1) 独立
- **典型应用**：方差推断、拟合优度检验
- **退化为**：Gamma(k/2, 1/2)

### student_t — t 分布

- **公式**：f(x) = Γ((ν+1)/2)/(√(νπ)Γ(ν/2))·(1+x²/ν)^{-(ν+1)/2}
- **均值**：E(X) = 0（ν>1）
- **方差**：Var(X) = ν/(ν-2)（ν>2）
- **构造**：t = Z/√(V/ν)，Z~N(0,1)，V~χ²(ν)
- **典型应用**：小样本均值推断、t 检验

### weibull — 韦布尔分布

- **公式**：f(x) = (k/λ)(x/λ)^{k-1}e^{-(x/λ)^k}，x≥0
- **典型应用**：可靠性工程、失效分析
- **特例**：k=1 退化为指数分布

### laplace — 拉普拉斯分布

- **公式**：f(x) = 1/(2b)·e^{-|x-μ|/b}，x∈ℝ
- **均值**：E(X) = μ
- **方差**：Var(X) = 2b²
- **典型应用**：金融收益尾部、LASSO 先验

### lognormal — 对数正态分布

- **公式**：f(x) = 1/(xσ√(2π))·e^{-(ln x-μ)²/(2σ²)}，x>0
- **均值**：E(X) = e^{μ+σ²/2}
- **典型应用**：收入分布、股价建模

### f — F 分布

- **公式**：f(x) = [Γ((d₁+d₂)/2)/(Γ(d₁/2)Γ(d₂/2))]·(d₁/d₂)^{d₁/2}·x^{d₁/2-1}·(1+d₁x/d₂)^{-(d₁+d₂)/2}
- **构造**：F = (U/d₁)/(V/d₂)，U~χ²(d₁)，V~χ²(d₂) 独立
- **典型应用**：方差分析、F 检验

### 离散分布

### bernoulli — 伯努利分布

- **公式**：P(X=1)=p，P(X=0)=1-p
- **均值**：E(X) = p
- **方差**：Var(X) = p(1-p)
- **典型应用**：一次成败试验
- **关系**：n 次独立伯努利之和 = Binomial(n,p)

### binomial — 二项分布

- **公式**：P(X=k) = C(n,k) p^k (1-p)^{n-k}，k=0,...,n
- **均值**：E(X) = np
- **方差**：Var(X) = np(1-p)
- **可加性**：独立 Binomial(nᵢ,p) 之和 ~ Binomial(Σnᵢ,p)
- **近似**：n 大时近似正态，np 适中时近似泊松
- **典型应用**：n 次独立试验成功次数

### poisson — 泊松分布

- **公式**：P(X=k) = λ^k e^{-λ}/k!，k=0,1,2,...
- **均值**：E(X) = λ
- **方差**：Var(X) = λ（均值=方差）
- **可加性**：独立 Poisson(λᵢ) 之和 ~ Poisson(Σλᵢ)
- **典型应用**：单位时间稀有事件计数

### geometric — 几何分布

- **公式**：P(X=k) = (1-p)^{k-1}p，k=1,2,...
- **均值**：E(X) = 1/p
- **方差**：Var(X) = (1-p)/p²
- **关键性质**：无记忆性（离散版）
- **典型应用**：首次成功所需试验次数

### negative_binomial — 负二项分布

- **公式**：P(X=k) = C(k+r-1, r-1) p^r (1-p)^k，k=0,1,...
- **均值**：E(X) = r(1-p)/p
- **方差**：Var(X) = r(1-p)/p²
- **特例**：r=1 退化为几何分布
- **典型应用**：第 r 次成功前的失败次数
